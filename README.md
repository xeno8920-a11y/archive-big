**Архивы Б.И.Г.** — это веб-интерактивный нарративный детектив с элементами мета-хоррора, созданный на React. Вы берете на себя роль инспектора, изучающего засекреченные сектора Большой Исследовательской Группы через терминал удаленного наблюдения.

🔗 **[НАЧАТЬ РАССЛЕДОВАНИЕ](https://xeno8920-a11y.github.io/archive-big/)**

## 👁️ Механики и особенности

*   **Доска расследования (Evidence Board):** Нажмите `[TAB]`, чтобы открыть пробковую доску. Перетаскивайте найденные документы (Drag-and-Drop), создавайте собственные заметки и связывайте улики красными нитями для поиска истины.
*   **Системный терминал (CLI):** Нажмите ``[`]`` или `[~]` для вызова командной строки. Используйте команды (`help`, `scan`, `ping`, `override`), чтобы анализировать сектора и вскрывать закрытые логи.
*   **Пространственный звук:** Интеграция Web Audio API. Звуки панорамируются в зависимости от расположения объектов на экране. Фоновый инфразвуковой саб-дрон (32.4 Гц) создает физическое ощущение давления бункера.
*   **Мета-нарратив:** Игра реагирует на смену вкладок браузера, ломает четвертую стену и имитирует аппаратные сбои видеокарты при неверных действиях.
*   **7 уникальных концовок:** От обычного побега до утилизации в биореакторе Б.И.Г. Все найденные финалы навсегда сохраняются в вашем личном Досье.

## ⚙️ Технический стек

Проект написан с использованием современных веб-технологий и оптимизирован для работы без бэкенда:
*   **Frontend:** React 18 (Hooks, условный рендеринг, кастомный UI).
*   **Audio:** Native Web Audio API (StereoPannerNode, Oscillators).
*   **Хранение данных:** Безопасная обертка `safeStorage` над `localStorage`, устойчивая к блокировкам браузера и режимам инкогнито.
*   **Графика:** Полностью кастомный SVG с CSS-анимациями и фильтрами (без тяжелых внешних изображений).
