## 👁️ Игровой лор и завязка

Комплекс **Б.И.Г.** (Большая Исследовательская Группа) скрывает под землёй километры бетонных коридоров, затопленных архивов и стерильных испытательных зон. Ваша задача — пройти сквозь изолированные сектора, собрать утерянные служебные документы, расшифровать скрытые директивы Смотрителя #44 и найти истинный путь к эвакуации, избежав цифровых ловушек системы.

## ⚙️ Уникальные механики

*   **📌 Доска расследования (Evidence Board):** Нажмите `[TAB]`, чтобы открыть пробковую доску. Перетаскивайте карточки документов и заметок, соединяйте их **красными нитями** для выстраивания логических цепочек расследования.
*   **⌨️ Системный терминал (CLI):** Нажмите ``[`]`` (или `[~]`), чтобы вызвать командную строку Б.И.Г. Анализируйте сектора, пингуйте узел надзора и просматривайте дампы памяти.
*   **🔦 Ультрафиолетовый фильтр (UV-спектр):** Переключайте спектр наблюдения в секторах, чтобы проявлять скрытые флуоресцентные пометки, предупреждения и системные эксплойты на стенах и объектах.
*   **🔊 Пространственный звук (Web Audio API):** Динамическое панорамирование звуков интерфейса и фоновый инфразвуковой саб-дрон (32.4 Гц), создающие физическое ощущение давления бункера.
*   **📂 Система Досье и 7 Концовок:** Все найденные финалы навсегда сохраняются в вашем личном Досье (даже между перезапусками сессии). Соберите их все, чтобы прочесть секретное письмо Основателя.

## 💻 Шпаргалка по командам терминала (CLI)

Вызвав консоль клавишей ``[`]``, вы можете использовать следующие системные команды:
*   `help` — вывести список всех доступных команд.
*   `scan` — запустить глубокий спектральный анализ текущего сектора.
*   `cat doc-1` (до `doc-4`) — вывести прямой текст найденных документов в консоль.
*   `ping 44.1` — проверить стабильность канала связи с постом Смотрителя.
*   `status` — показать сводку собранных документов, зацепок и открытых концовок.
*   `override` — принудительный тест видеобуфера (сбой драйвера).
*   `clear` — очистить историю экрана консоли.

## 🗂️ Архитектура проекта

Проект спроектирован без тяжёлых сборщиков (Vite/Webpack) и работает прямо в браузере за счёт бесшовной модульной структуры:
*   `index.html` — главная точка входа, подключение шрифтов, стилей и очерёдности скриптов.
*   `style.css` — кастомные стили интерфейса, CRT-эффекты, анимации и сканирующие сетки.
*   `sound.js` — процедурный звуковой движок на базе нативного Web Audio API.
*   `data.js` — вся текстовая база, лор, каталог концовок и массив уровней (`LEVELS`).
*   `app.jsx` — основная логика интерфейса, React 18 хуки, рендеринг SVG-сцен и обработчики состояний.
